Help & Conventions

How to write grammars in CFG Studio and what each tool does.

Quick start
  1. Define a grammar in the Editor — or load a ready-made example from My Grammars. The validation panel reacts as you type.
  2. Open CNF Conversion to transform the grammar into Chomsky Normal Form, one explained step at a time.
  3. In the CYK Simulator, type a string and watch the algorithm fill its table cell by cell until the verdict.
  4. If the string is accepted, explore its derivation in the Parse Tree — drag to pan, scroll to zoom, export as SVG.
Writing grammars
Variables (V) Start with an uppercase letter, may continue with letters, digits or _ — e.g. S, A, X1, T_a. Separate with spaces or commas.
Terminals (Σ) Single non-uppercase characters — e.g. a b 0 ( ) + *. Separate with spaces. |, ε and λ are reserved.
Productions (P) One line per variable: choose the left-hand side, then type the alternatives — e.g. ( S ) | S S | ε. Spaces between symbols are optional (declared symbols are recognised by longest match).
Empty string Use the ε button, or type ε, epsilon, eps or lambda as an alternative on its own.

Your work is auto-saved as a draft in the browser on every change. Press Ctrl+S (or the Save button) to store a valid grammar on the server, and use Export / Import for JSON files.

The tools, in one paragraph each
Validation
Checks that the grammar is a well-formed CFG (declared symbols, valid start symbol, no duplicates…) and warns about useless structure: variables that are unreachable from the start symbol or can never derive a terminal string.
CNF conversion
Rewrites the grammar so every rule is A → B C or A → a (plus S → ε if ε belongs to the language), through six classic stages — START, TERM, BIN, DEL, UNIT, CLEANUP — each shown with the rules it adds or removes and why.
CYK simulator
The Cocke–Younger–Kasami dynamic-programming algorithm decides membership in O(n³·|P|): cell (i, l) collects the variables deriving the substring at position i of length l, built bottom-up from shorter substrings. The animation replays exactly the steps the algorithm performed.
Parse tree
Reconstructed from the CYK table's backpointers; shows the derivation tree of the CNF grammar together with the leftmost derivation it encodes.
Limits
  • CYK input strings: at most 30 characters (the table and the O(n³) trace must stay readable).
  • Grammars: at most 200 productions, 100 variables, 100 terminals — far beyond any classroom example.
  • Only valid grammars can be saved on the server; drafts of any state live in your browser.
About CFG Studio

CFG Studio is an educational workbench developed as a Bachelor's Thesis: “Development of a Web Application for the Design and Computation of Context-Free Grammars (CFGs)”. It focuses exclusively on context-free grammars — in the spirit of classroom tools like JFLAP, but built for the web.

Node.js · Express · vanilla JavaScript (ES modules) · Bootstrap 5 · Jest. The algorithm modules run identically in the browser, on the server and in the test suite.
